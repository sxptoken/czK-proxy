# czX Search — GitHub + Vercel

A dark czX search homepage that fetches DuckDuckGo HTML server-side and displays parsed search results inside the czX page.

## GitHub → Vercel

Upload these files to the ROOT of the GitHub repository:

- `index.html`
- `style.css`
- `vercel.json`
- `package.json`
- `api/search.js`

The `api` folder must stay named `api`.

Then import the GitHub repository into Vercel and deploy.

No API key or environment variables are required.

## Important

Do not upload the ZIP file itself. Extract it first, then upload the files/folders inside it.
