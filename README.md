# czX

GitHub + Vercel DuckDuckGo search page.

## Deploy

1. Upload every file in this folder to the root of a GitHub repository.
2. Make sure `index.html`, `style.css`, `vercel.json`, `package.json`, and the `api` folder are in the repository root.
3. Import the repository into Vercel.
4. Vercel should detect the project automatically.
5. Deploy.

No environment variables are required.

## Important

Do not upload the ZIP itself into the repository. Extract it first and upload the files inside it.
